## 1. 서비스 기획 및 요구사항 정의
- **아이디어**: 병원 진료 후 복잡한 실손보험 청구액과 자기부담금을 자동 계산해 주는 인슈어테크 웹 서비스
- **핵심 기술 스택**: 
  - 프론트엔드: 순수 바닐라 HTML5, CSS3, JavaScript (SPA 반응형)
  - 백엔드: Vercel Serverless Function (Python 3.10+ / BaseHTTPRequestHandler)
  - AI 모델: Google Gemini 2.5 Flash (멀티모달 Vision + Text)
- **예외 처리 설계**: 빈 입력 방어, 로딩 인디케이터, API 4xx/5xx 에러 핸들링

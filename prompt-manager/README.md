# 📌 나만의 프롬프트 관리자 (Prompt Manager)

> AI 프롬프트 템플릿을 체계적으로 수집, 검색, 조회 및 분류 관리하는 파이썬 기반 CLI 도구입니다.

---

## 1. 프로젝트 개요
* **목적**: 생성형 AI 활용 시 반복 사용되는 고품질 프롬프트를 체계적으로 저장하고, 키워드 검색 및 카테고리 필터링을 통해 재사용성을 높이기 위해 개발되었습니다.
* **핵심 기술**: Python 기본 자료구조(List, Dict), 제어문/반복문, Git 기능별 브랜치 운용 및 단위 커밋 관리.

---
